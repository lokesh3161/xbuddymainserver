            XBUDDY PRINT AGENT — SHOP PACKAGE

Welcome to XBuddy!

QUICK START INSTRUCTIONS:
1. Extract all files from this ZIP archive into a folder.
2. Double-click "START X BUDDY.bat".
3. The launcher will automatically:
   - Check Node.js
   - Install required dependencies if missing
   - Connect to your Google Apps Script backend
   - Detect your local Windows printer
4. Status will change to: 🟢 SHOP ONLINE

CONFIGURATION:
Your shop settings are pre-configured in config/shop-config.json.
You do NOT need to edit any files manually.

LOCAL STATUS:
Local Agent URL: http://localhost:3001
Status & Health: http://localhost:3001/status
